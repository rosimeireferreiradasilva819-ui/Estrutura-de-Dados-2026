# Estrutura de Dados

A disciplina de Estrutura de Dados apresenta maneiras de organizar, armazenar e manipular informações. O estudo dessas estruturas ajuda a desenvolver algoritmos mais claros e eficientes.

## Principais assuntos

- Algoritmos, variáveis e tipos de dados;
- Vetores e matrizes;
- Listas, pilhas e filas;
- Árvores e grafos;
- Busca e ordenação de dados;
- Noções de complexidade e eficiência.

Os exemplos e atividades da disciplina são desenvolvidos em linguagem C.
